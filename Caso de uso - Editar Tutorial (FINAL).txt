Caso de uso - Editar tutorial
Precondições: Estar logado no sistema como Admin
Autores: Admin
Trigger: Clicar no "Editar Tutorial"

Fluxo Principal:
1. Admin clica no botão de "Editar tutorial" na página "index"
2. Redireciona o Admin para "edit_tutorial"
3. Admin modifica as informações do tutorial
4. Sistema armazena os dados inseridos utilizando o model
5. Atualiza o Tutorial no sistema
6. Redireciona o Admin para a página "index"

Fluxo alternativo:
... Durante qualquer momento do fluxo principal, o Admin desiste da ação e retorna para a tela "index"
