Caso de uso: 'Editar tutorial': Admin altera tutorias
Precondicoes: Estar logado como admin
Autores: Admin
Trigger: Admin clica no botao de adicionar conteudo

1. O aplicativo mostra a pagina para editar o tutorial
2. Admin altera informações sobre o tutorial
3. Sistema salva as alterações do tutorial tutorial
4. Sistema volta para a página inicial
